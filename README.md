This is portfolio website frontend project. I commit styles, features and implement my own design.

- React App (Node JS)
- Start at root folder

Start the website:
1. Open VS Code terminal.
2. Run `npm install` to install the React App dependencies (wait for install)
3. Run `npm run start` to run a local version of the website.
4. After `"Compiled successfully!"` open your browser and visit localhost

Local Host: `"http://localhost:3000"`

To END the local React App running:
1. Open the active VS Code terminal.
2. `CTRL + C` to stop the React App.
